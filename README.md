# JalebiScoreboard

Sidebar scoreboard for JALEBI SMP (Paper 1.21.7+, Vault for money).

- `/scoreboard` (`/sb`) opens a dialog screen to toggle: scoreboard, name, money, kills, deaths, playtime, shards

## Build
Push to GitHub, then open the **Actions** tab, pick the latest run and download the
`JalebiScoreboard` artifact. Or locally: `mvn package` (Java 21).
